Ver `DECISIONS.md`: Next.js + Bun en lugar de Vite; estilo visionOS; advisory cian como supuesto; moon en el repo, sin descargar herramientas; CI con `moon ci`.

## Qué se encontró

- Las guías de Apple para visionOS encajan con el PRD: escala neutra, color solo para estado y en texto en negrita, números visibles.
- El vidrio baja el contraste: sirve para Planning; la vista EV pide paneles más sólidos.
- Los materiales de visionOS son capas con modos de fusión; en la web solo funcionan si ningún ancestro crea un stacking context (`transform`, `opacity`, `sticky`…).
- `tailwind-merge` borraba los tamaños de texto propios (`text-caption-1`) al lado de un color: se registraron los tokens.
- Next 16.4 trae Cache Components y Partial Prefetching activados por defecto en el template.
- `moon init` toma como rama principal la rama actual (`web/base`): se corrigió a `main`.
- Para fijar y descargar versiones, moon usa proto, que guarda todo en `~/.proto`. Para no instalar nada fuera del repo, moon usa las herramientas del sistema.
- Las tareas de Python de moon necesitan el entorno instalado (`pip install -e ".[dev]"`); en la Mac de Eitan todavía no está.
