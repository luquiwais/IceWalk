# design/

Dueño: Diseño UX/UI. Exports de Figma, íconos, assets del teaser.

Reglas (de NASA-STD-3001 y prácticas de interfaces de tripulación, ver PRD):

- Color solo para estado y alertas; resto en escala neutra.
- Alertas en tres niveles: advisory, caution, warning.
- Mismos componentes y posiciones en Planning y EV.
- Vista EV: alto contraste, tipografía grande, operable con guantes.
- Interfaz en inglés, terminología NASA (EV1/EV2, station, traverse, egress/ingress, walkback).
- Créditos de imágenes: NASA/JPL-Caltech/UArizona (HiRISE).
