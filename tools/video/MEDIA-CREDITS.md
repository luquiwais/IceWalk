# IceWalk video media

The pinned media release accompanies the Blender and Remotion source in this
directory. Each third-party asset retains its original license; the repository's
license does not replace it. Paths below are relative to `tools/video`.

- **Astronaut:** “Animated Astronaut Character in Space Suit Loop” by
  [LasquetiSpice](https://sketchfab.com/LasquetiSpice),
  [original model](https://sketchfab.com/3d-models/animated-astronaut-character-in-space-suit-loop-8fe5c8d3365e4d87bb7bc253d53a64e1),
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
  Materials, animation and poses adapted for IceWalk. Original license and source
  metadata are in `assets/third-party/lasqueti-astronaut/`.
- **Motion capture:** CMU Graphics Lab, NSF EIA-0196217;
  [CMU database](http://mocap.cs.cmu.edu/). BVH conversion by Bruce Hahne /
  cgspeed. The included `assets/mocap/cmu/READMEFIRST.txt` preserves the source
  description and usage terms.
- **Terrain scans and PBR textures:** [Poly Haven](https://polyhaven.com/), CC0,
  in `assets/polyhaven/`. Illustrative surface microdetail, not measured Martian
  rock or soil properties.
- **HiRISE imagery and terrain:** NASA/JPL-Caltech/UArizona; DTM
  `DTEEC_073578_2155_073077_2155_A01`, USGS. Prepared site crops and heightmaps
  are in `public/site/` and `public/data/`.
- **NASA imagery, 3D models and archive excerpts:** NASA and credited mission
  partners; original filenames retained in `assets/nasa/` and `public/nasa/`.
  NASA/JPL-Caltech/LANL/CNES/IRAP for the Perseverance SuperCam wind recording,
  `assets/sfx/nasa/45827_SCAM_MIC_SOL004_RUN001.wav`.
  [NASA media guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/)
  applies; this work does not imply NASA endorsement.
- **Voices:** synthetic Gemini Orus (Mission/IV) and Charon (EV), directed for
  IceWalk. Included takes allow rendering without an API key or new generation.
- **Music, sound design, screen layouts and scene assembly:** IceWalk production
  scripts. App captures represent the recorded build, with the limitations in
  the [production log](../../docs/log/2026-11-15.md).

`out/IceWalk-Credits.txt` accompanies the exported films. The media release omits
downloaded videos/screenshots of other teams, personal generation trackers,
emails, raw chat logs and local credentials.
